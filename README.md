# SysCloak
SysCloak: a Windows privacy utility that disables AI, ads, recommendations and suggestions



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Microsoft (Windows) options:
  * Copilot: disable Windows Copilot and the Copilot taskbar button
  * Edge User Interface: turn off backstack, recent apps and most-frequently-used apps tracking
  * Location And Sensors: disable location, location scripting, sensors, Windows location provider (admin)
  * Windows AI: disable AI data analysis (Recall), Click to Do, Recall enablement, saving snapshots
* Apps options:
  * Microsoft Edge policies: Copilot page context, Bing Chat on the new tab page, sidebar, recommendations,
    shopping/wallet/feedback features and more (admin)
* Each option shows its Windows default; right-click to check/uncheck all
* Options that need administrator rights are shown only when SysCloak runs as administrator
* Logs actions to a file
